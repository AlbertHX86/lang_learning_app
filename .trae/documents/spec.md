# 多语种在线教育平台 - 需求规范文档

## 1. 项目概述
多语种在线教育平台，提供沉浸式语言学习体验，支持英语、日语、韩语等主流语言。
- 解决用户语言学习缺乏系统化、互动性差的问题，为学习者提供全面的语言学习工具。
- 目标用户为语言学习者，市场价值在于提供个性化、高效的语言学习解决方案。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------------------|------------------|
| 普通用户 | 邮箱注册 | 访问所有学习功能，跟踪进度，加入社区 |
|  premium用户 | 邮箱注册 + 付费 | 访问所有功能 +  premium内容 |

### 2.2 功能模块
1. **首页**：英雄区、语言选择、课程分类、推荐课程
2. **课程页**：课程详情、课程列表、进度跟踪
3. **学习模块**：词汇练习、语法练习、口语练习、听力训练
4. **个人中心**：用户信息、学习统计、成就徽章
5. **社区页**：讨论论坛、学习小组、同伴反馈

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 首页 | 英雄区 | 动态语言学习场景，语言选择器，行动号召按钮 |
| 首页 | 课程分类 | 按语言和级别筛选课程，热门课程展示 |
| 课程页 | 课程详情 | 课程描述，级别信息，预计完成时间 |
| 课程页 | 课程列表 | 结构化课程进度，已完成课程标记 |
| 学习模块 | 词汇练习 | 闪卡，间隔重复，发音音频 |
| 学习模块 | 语法练习 | 互动测验，即时反馈，解释资源 |
| 学习模块 | 口语练习 | 语音录制，发音评估，与母语者比较 |
| 学习模块 | 听力训练 | 音频剪辑，理解问题，速度调整 |
| 个人中心 | 学习统计 | 进度图表，学习时间，解锁成就 |
| 个人中心 | 成就徽章 | 里程碑的视觉表示，持续学习的奖励 |
| 社区页 | 讨论论坛 | 基于主题的线程，语言特定频道，专家回答 |
| 社区页 | 学习小组 | 创建或加入小组，共享学习目标，小组活动 |

## 3. 核心流程
### 主要用户流程
1. 用户注册/登录平台
2. 选择目标语言和熟练程度
3. 浏览并注册课程
4. 参与互动学习模块
5. 跟踪进度并接收个性化推荐
6. 参与社区活动并获得成就

## 4. 技术架构
- 前端：React@18 + TypeScript + Tailwind CSS@3 + Vite
- 后端：Express@4 + TypeScript
- 数据库：Supabase (PostgreSQL)
- 认证：Supabase Auth
- 存储：Supabase Storage (用于音频文件，用户头像)
- 外部API：用于语言学习的文本转语音和语音转文本服务

## 5. 路由定义
| 路由 | 用途 |
|-------|---------|
| / | 首页，包含语言选择和课程分类 |
| /courses | 课程列表页 |
| /courses/:id | 课程详情页 |
| /learn/:courseId/:lessonId | 学习模块页面 |
| /profile | 用户个人资料页面，包含学习统计 |
| /community | 社区论坛页面 |

## 7. 设计规范
### 7.1 设计风格
- 主色：#4361ee (蓝色)
- 辅助色：#3f37c9 (深蓝色)
- 强调色：#4895ef (浅蓝色)
- 按钮风格：圆角 (8px)，微妙阴影，悬停效果
- 字体：Inter (无衬线) 用于正文，Poppins (无衬线) 用于标题
- 字体大小：16px (正文)，24px (h2)，32px (h1)
- 布局风格：基于卡片的设计，干净的空白，响应式网格
- 图标风格：极简主义，基于线条的图标，带有微妙的动画

### 7.2 响应性
- 桌面优先设计，具有移动自适应布局
- 断点：360px (移动)，768px (平板)，1200px (桌面)
- 移动设备的触摸优化，具有更大的点击目标和滑动手势
- 移动设备的可折叠导航菜单，桌面的扩展侧边栏
